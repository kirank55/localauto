How it fills

Three actions, and then it stops.

Fill does not run while you type. Learning is a list you review. A different wording is shown, and left alone, until you accept that one field.

  1. 01

    Fill empty fields

    Writes the profile, and any exact question, into fields that are still empty. A value you already typed stays. Hidden, password, and payment fields are skipped.

  2. 02

    Find answers to save

    Lists the questions on the page. You uncheck anything you do not want kept. Name, email, phone, and links are profile fields, so they are not stored a second time as questions.

  3. 03

    Accept

    Writes one suggestion. You can see the source question. Fill itself never applies a paraphrase.

Rules

How a question is judged.

Matching runs in this order. Embeddings are not in this version. The laboratory uses the same checks as the beta: a canonical question, country phrases, number slots, yes/no, and a shared significant word.

  1. Profile slots, from the control itself: type, autocomplete, name, and a short label. The order is email, phone, LinkedIn, GitHub, website, first name, last name, then full name. A full name splits on the first space. A one-word name fills First name and leaves Last name empty. Lever’s single Name field gets the whole name. A long question that merely mentions email stays empty.
  2. Exact reuse, when the question matches aside from case, accents, and punctuation. Dotted forms are expanded first, so “U.S.” is not the same question as “United States”. The newest saved answer wins. Saving the same question again replaces the old answer.
  3. A suggestion, only when the country, yes/no, and numbers agree, the questions share a significant word, and you accept it. One suggestion per question. A slot conflict never becomes a suggestion.

“US” counts in “the US”, “U.S.”, “USA”, and “United States”. It does not count in “tell us”. England, Scotland, and Wales count as the UK slot. A significant word is longer than two letters, is not a common word such as “the” or “you”, and does not start with a digit. At most 300 answers are kept. Saved answers are reused across Greenhouse and Lever.

Laboratory

Two wordings

Numbers are read from the question, not from the answer. A saved answer of 5 does not put a 5 in the number slot. The saved question’s yes/no flag comes from its wording. The checkbox adds the flag a Yes/No control would add. Turn it off on “Not a question” and that pair is withheld.

Safety

What Fill will not touch.

Fill writes through the page’s own value setter and dispatches input and change, so the form’s state updates. It still refuses more than it writes.

  • It runs when you click, and only on empty visible fields. A correction you already typed stays.
  • A hidden field is counted and left alone, including a honeypot.
  • Password fields, and payment fields such as a card number or CVV, are named in the result and never written.
  • Disabled, read-only, file, button, and date controls are ignored.
  • The extension does not request browsing history. Greenhouse forms often sit in an iframe, so each frame reports its own result and the side panel merges them.
  • The profile and the saved answers live in the extension’s own storage, chrome.storage.local. The job site cannot open that store. Clearing the site’s data does not clear it. Removing the extension does.

Left alone

  • Notes Shipped the beta Already filled
  • Password Empty Named, not written
  • Card number Empty Named, not written
  • Hidden field Not shown on the page Counted
  • What email should we use to reach your referee? Empty Not a profile slot

Personalities

More than one name. One list of answers.

A personality is a named profile. The starters are Default, Personal, Work, and Software engineer. Default is selected until you choose another, including when an older single profile is read. You can add a name, up to 12. Default cannot be deleted. Settings, opened from the side panel, is where you delete one, pause a host, or turn the submit prompt on or off.

Each personality keeps its own name, email, phone, and links. Saved answers stay one list, because a question is reused across hosts. Splitting that list would hide a confirmed answer on the next form. The cards are examples. Starters begin empty.

Hosts

Where it runs.

A fixed list, plus the local demo. You can pause Greenhouse, Lever, or the demo. There is no way to add an arbitrary site. Company subdomains and EU Greenhouse hostnames are not in this beta.

Host access

https://boards.greenhouse.io/*
https://job-boards.greenhouse.io/*
https://jobs.lever.co/*
http://localhost/*
http://127.0.0.1/*

Chrome asks to read and change data on those hosts. That is how Fill reaches the page. The extension does not run anywhere else, and it does not request browsing history.

Not in this beta

  • Embeddings
  • Workday
  • LinkedIn Easy Apply
  • Ashby, Indeed, Comeet
  • Arbitrary sites
  • Silent save on submit

A form inside an iframe is filled too. Each frame reports its own fields, which is why a history permission is not required.

Install

Install the extension.

You need Chrome 116 or newer. The beta is an unpacked extension, not a store install yet.

  1. Download localauto-<version>-chrome.zip and its .sha256 file from the latest release.
  2. Check the sum with sha256sum -c localauto-<version>-chrome.zip.sha256, then unzip into a folder you will keep. On macOS, shasum -a 256 -c with the same file.
  3. Open chrome://extensions and turn on Developer mode.
  4. Choose Load unpacked and select the unzipped folder.
  5. Pin Localauto. Click the icon to open the side panel.

To update, unzip the new release over the same folder and press reload on the Localauto card. Your profile and saved answers stay. Tabs that were already open work on the first Fill, without a reload.

Build from source

You need Node 22 or newer. Load .output/chrome-mv3 the same way.

npm install
npm test
npm run build

Demo

npm run demo

Open http://127.0.0.1:4173 for the Greenhouse-style form, the Lever-style form, a second form with paraphrased questions, the same Greenhouse form inside an iframe, and a submit button.

Try

npm run try

That opens Playwright’s Chromium with the extension loaded and the side panel in front. Install that browser once with npx playwright install chromium. Close the window to stop.

Then use it

  1. Enter your name, email, phone, and links, then Save profile. The personality button switches between Default, Personal, Work, Software engineer, and profiles you create. Fill empty fields writes the selected profile into empty visible fields.
  2. Answer a custom question. Choose Review answers on this form, uncheck anything you do not want kept, then Keep. Settings lists every saved answer and deletes any of them.
  3. On the next application, Fill empty fields again. The same question fills. A different wording shows under Suggestions with the source question. Accept writes that one field.
