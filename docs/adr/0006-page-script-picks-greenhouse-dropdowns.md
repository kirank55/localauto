# A page script picks Greenhouse dropdowns

Greenhouse job boards draw yes/no and choice questions with react-select. The chosen option lives in the component, not in the input, and the menu ignores the untrusted key and mouse events a content script can send. Typing into the search box changes nothing and used to be reported as filled. A second content script runs in the page's main world, finds the component through React's fiber on the input, and calls its own `selectOption`, the path a click takes. The content script asks for an option with an attribute and an event on the input and reads the answer back before `dispatchEvent` returns. The page script holds no saved data and only selects options the page already offers. `chrome.debugger` could send trusted input but shows a warning bar and a scarier permission. A combobox that is not react-select stays a text field, as before.
