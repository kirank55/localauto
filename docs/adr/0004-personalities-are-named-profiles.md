# A personality is a named profile, and saved answers stay shared

People keep more than one name and inbox. Localauto stores each as a personality: Default, Personal, Work, Software engineer, or a name they add. Default is selected until they pick another, including when an older single profile is read. Saved answers stay one list, because a question is reused across hosts and splitting that list by personality would hide a confirmed answer on the next form. The settings page adds and removes personalities, pauses a host, and turns the submit prompt on or off. A submit opens the side panel and copies profile fields into the profile form. Save profile keeps them. Custom questions stay on Find answers to save.
